# Officely

Officely is a full-stack workplace booking platform developed as a student team project. The goal was to build a realistic multi-platform system that supports office discovery, offer browsing, booking management, and reservation handling across web and mobile applications.

## Project structure

- **frontend-web** — web application for administration and system management
- **frontend-mobile** — mobile application for end users, built with Expo
- **officely-backend** — backend API, business logic, and data layer

## Core functionality

- authentication and user access flows
- browsing offices and available offers
- creating and managing bookings
- user reservation and profile handling
- admin tools for managing offices, users, and bookings
- partner parking integration
